## Запуск

```bash
git clone URL && cd REPO
cp .env.example .env
make up
```

→ http://localhost:3000 · API: http://localhost:8000/docs

Нужен только Docker. Проверено на чистой машине.

make seed      # демо-данные
make eval      # воспроизвести замер метрик
