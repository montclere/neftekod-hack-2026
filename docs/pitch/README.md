# Упаковка

Всё, что нужно на последних 20% срока: витрина репозитория и презентация.

## Витринный README — два варианта

Равноправны. **Отличаются только шапкой и футером** — разделы, тексты и структура
идентичны, палитра отличается оттенками под способ отрисовки.

| Вариант | Шапка и футер | Плюс | Минус |
|---|---|---|---|
| [`README-svg.md`](README-svg.md) | локальные `docs/design/header.svg`, `footer.svg` | ни от кого не зависит, текст правится буквами прямо в SVG, палитра — в `<defs>` | файлы надо держать в репозитории |
| [`README-external.md`](README-external.md) | capsule-render + readme-typing-svg по URL | в репозиторий класть нечего, есть анимированный бегущий питч | картинки на чужих серверах: лягут — витрина пустая. Кириллица требует percent-encoding |

Выбрали — копируете в корень и правите уже там:

```bash
cp docs/pitch/README-svg.md README.md      # или README-external.md
```

До этого момента в корне лежит рабочий README с быстрым стартом — тот, что читает
команда. Подменять его стоит в фазе упаковки, не раньше: пока идёт разработка,
напарнику нужны команды запуска, а не бейджи.

**В обоих вариантах:** бейджи и блок «Запуск» помечены предупреждениями. Бейджи
там — пример под чужой RAG-кейс, команды надо сверить с `make help`. Жюри выполняет
то, что написано.
